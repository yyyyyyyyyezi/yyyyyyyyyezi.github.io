怎么写新文章

在 src/content/posts/ 下新建一个 .md 文件，或者运行：

npm run new -- post 文章标题

写完 git push，Cloudflare Pages 会自动构建上线。

把 frontmatter 里的 draft 设为 true，文章就只在本地预览时显示。
